## 🌟 Executive Summary

This repository documents the complete academic coursework, programming projects, laboratory deliverables, computational notebooks, and theoretical problem sets completed during my undergraduate studies at the **Department of Computer Science (CSD), University of Crete (UoC)**.

Having completed the first 4 semesters (spanning the core mathematical, theoretical, hardware, and systems foundations of computer science) with **21 out of 21 courses passed (0 backlog)** and **138 ECTS** earned toward the 240 ECTS degree requirement, this portfolio demonstrates proficiency across:
* **Low-Level Systems & Software Design:** ANSI C (C89/C90), POSIX environments, manual dynamic memory management (with zero Valgrind leaks), dynamic data structures, and computer organization (MIPS Assembly).
* **Object-Oriented Architecture & Mobile Engineering:** Modern C++ (C++17), Java (8/17/25), Model-View-Controller (MVC) architectural design, event-driven Swing GUIs, and native Android application development.
* **Scientific Computing & Signal Analysis:** Python 3, NumPy, SciPy, Matplotlib, Fast Fourier Transforms (FFT), audio processing, and computational physics simulations.
* **Mathematical & Theoretical Rigor:** Calculus I & II, Linear Algebra, Discrete Mathematics, Mathematical Logic, Probability & Statistics, Theory of Computation, and Algorithms & Complexity.

## 🛠️ Quickstart Build & Execution Guide

### 1. Launching the "Amphipolis" Java Board Game (HY-252)
```bash
cd ./Semesters/3/HY-252-OOP-Java-Android/Project
java -jar Amphipolis.jar
```

### 2. Building the 3D Ray Tracing Engine in C++17 (HY-150)
```bash
cd ./Semesters/2/HY-150-Cpp-Programming/HW-02
cmake -B build
cmake --build build
./build/assignment2
```

### 3. Compiling the Library Data Structures Engine in C (HY-240)
```bash
cd ./Semesters/3/HY-240-Data-Structures/Project
gcc -Wall -Wextra -std=c99 Library.c -o library_system
./library_system
```

### 4. Compiling the ANSI C Symbol Table ADT (HY-255)
```bash
cd ./Semesters/4/HY-255-Systems-Programming/HW-03
make list
./testsymtab
make clean
make hash
./testsymtab
```

### 5. Building the Mobile Sudoku Solver Android App (HY-252)
```bash
cd ./Semesters/3/HY-252-OOP-Java-Android/Android
./gradlew assembleDebug # Linux / macOS
gradlew.bat assembleDebug # Windows
```

## 📖 Course Overview

HY-215 bridges advanced mathematics and computer science applications, focusing on Fourier analysis, digital signal processing (DSP), differential equations, and numerical computing using Python.

## 📋 Course Topics
* **Fourier Analysis:** Continuous Fourier Transform (CFT), Discrete-Time Fourier Transform (DTFT), Discrete Fourier Transform (DFT), Fast Fourier Transform (FFT) algorithms ($O(N \log N)$), frequency-domain analysis.
* **Signal Processing:** Sampling Theorem (Nyquist-Shannon), aliasing, windowing techniques (Hamming, Hanning, Rectangular), audio filtering (low-pass, high-pass, band-pass), spectrogram visualization.
* **Numerical Methods:** Numerical differentiation, numerical integration (Riemann, Trapezoidal, Simpson's rules), root-finding methods (Newton-Raphson, Bisection).
* **Linear Systems & Convolutions:** Linear Time-Invariant (LTI) systems, impulse response, discrete convolution in time and frequency domains.

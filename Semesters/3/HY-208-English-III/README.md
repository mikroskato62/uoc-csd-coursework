## 📖 Course Overview

HY-208 focuses on advanced professional communication, technical documentation, and scientific writing in computer science. Students develop skills in writing technical reports, software documentation, project specifications, and professional CV/resumes.

## 📋 Key Syllabus Topics
* Structure and style of formal technical reports and system specifications.
* Writing abstracts, introductions, and methodology sections for CS research papers.
* Professional software engineering communication: issue tracking, pull request summaries, and team documentation.
* Assessment was completed through written technical essays, reports, and final examination.

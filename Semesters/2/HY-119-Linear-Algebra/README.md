## 📖 Course Overview

HY-119 covers matrix theory, vector spaces, and linear transformations, forming the mathematical foundation for computer graphics, 3D transformations, data science, and scientific computing. The course blends rigorous theoretical proofs with algorithmic Python implementations.

## 📋 Course Topics
* **Systems of Linear Equations:** Gaussian elimination, Gauss-Jordan row reduction, elementary row operations.
* **Matrix Factorizations:** LU decomposition, LDU factorization, Cholesky decomposition, permutation matrices.
* **Vector Spaces & Subspaces:** Linear independence, spanning sets, basis, dimension, the Four Fundamental Subspaces (Column Space, Null Space, Row Space, Left Null Space), Rank-Nullity Theorem.
* **Orthogonality & Projections:** Inner products, Gram-Schmidt orthogonalization, QR decomposition, least-squares approximation.
* **Eigenvalues & Eigenvectors:** Characteristic polynomials, diagonalization, symmetric matrices, Spectral Theorem, Positive Definite matrices.

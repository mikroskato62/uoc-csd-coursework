# Exercise 01: MIPS Architecture & SPIM Simulator Setup

> **Course:** HY-225 — Computer Organization (Οργάνωση Υπολογιστών)  
> **Topic:** Environment Setup & MIPS Architectural Fundamentals  

---

## 📖 Overview
Exercise 01 serves as an introductory laboratory module covering:
* Installation and configuration of the SPIM / MARS MIPS R2000/R3000 simulator environments.
* Memory segment orientation: Text segment (code instructions), Data segment (static/global data), Heap, and Stack.
* Register architecture orientation: General-purpose registers (`$zero`, `$t0-$t9`, `$s0-$s7`, `$a0-$a3`, `$v0-$v1`, `$gp`, `$sp`, `$fp`, `$ra`).
* Initial assembly file execution and step-by-step register tracing.
